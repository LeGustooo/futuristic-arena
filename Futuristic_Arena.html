Gruppe erstellen: Map wählen, Neu drücken, Code an Freunde schicken (der Code legt die Map fest). Wer denselben Code eingibt, spielt privat mit dir. Bots gibt es nur, solange du allein bist. Freunde müssen vorher über Teilen eingeladen sein.
x
x
Am PC: Maus bewegen = umschauen, ohne Klicken oder Halten. Linksklick = Schlagen, Rechtsklick = Bombe. Das Fadenkreuz in der Mitte zeigt, wohin die Bombe fliegt. Doppelsprung: in der Luft nochmal springen. Bodenschlag: in der Luft Hocken drücken. Power-ups einsammeln: Heilung, Speed, Rapid-Fire.
Controller: Linker Stick = bewegen, rechter Stick = umschauen, A = springen, X oder RB = schlagen, RT = Bombe, LT = sprinten, L3 = Dash, B = hocken, Y = Kamera, LB = 180-Grad-Drehung, R3 (rechten Stick eindrücken, halten) = nach hinten schauen, Start = Pause. Im Menü: Steuerkreuz oder linker Stick wählen, A bestätigt, Start startet oder pausiert.
